## 一、这东西是干什么的

### 没装之前

你的矿机直接连矿池代理，中间这段流量是**明文**的，特征很明显：

```
  ┌─────────┐                                    ┌─────────┐
  │  矿机   │ ━━━━━━━ 明文流量 ━━━━━━━━━━━━━━━━▶ │ 矿池代理│
  │ Antminer│      一眼就能看出是挖矿            │         │
  └─────────┘                                    └─────────┘
                        ▲
                        │
                  ┌───────────┐
                  │ 能看到内容 │
                  │ 能识别能拦 │
                  └───────────┘
```

### 装了之后

在矿机和服务器之间加一个"中转站"，把流量伪装成正常上网：

```
  ┌─────────┐          ┌──────────┐                    ┌─────────┐
  │  矿机   │ ───────▶ │  SSLMIX  │ ══════════════════▶│ 服务器  │
  │ Antminer│  明文    │  客户端  │   加密，看起来像    │         │
  └─────────┘ (局域网) └──────────┘   普通 HTTPS 上网   └─────────┘
                        装在你这边              ▲
                                                │
                                          ┌───────────┐
                                          │ 只看到一堆 │
                                          │ 加密乱码   │
                                          └───────────┘
```

**矿机本身不用改任何设置**，只要把矿池地址改成指向 SSLMIX 客户端就行。

## 二、工作原理

### 2.1 三个角色

```
   ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
   │   ① 矿机     │     │  ② SSLMIX    │     │  ③ 服务器    │
   │              │     │    客户端    │     │              │
   │ 你机房里的   │────▶│ 你自己装的   │────▶│ 后台管理端   │
   │ 挖矿设备     │     │ 一个小程序   │     │ 在公网       │
   └──────────────┘     └──────────────┘     └──────────────┘
      不用动            本教程装的就是它        管理员配置好的
```

### 2.2 客户端启动后做了什么

```
  ┌────────────────────────────────────────────────────────┐
  │  第 1 步：读配置文件                                    │
  │  ────────────────────────────────────────────────────  │
  │  程序启动 → 找同目录下的 apiSslMixConfig.json          │
  │             ↓                                          │
  │        文件里存着服务器地址（加密的）                   │
  └────────────────────────────────────────────────────────┘
                            ↓
  ┌────────────────────────────────────────────────────────┐
  │  第 2 步：连服务器要配置                                │
  │  ────────────────────────────────────────────────────  │
  │  客户端 ──"我是xxx，给我配置"──▶ 服务器                │
  │  客户端 ◀──"你监听3333端口，转发到1.2.3.4:9999"── 服务器│
  └────────────────────────────────────────────────────────┘
                            ↓
  ┌────────────────────────────────────────────────────────┐
  │  第 3 步：开本地端口等矿机                              │
  │  ────────────────────────────────────────────────────  │
  │  客户端在本机打开 3333 端口，开始监听                   │
  │  控制台会显示：Conn-Port-01:3333                       │
  └────────────────────────────────────────────────────────┘
                            ↓
  ┌────────────────────────────────────────────────────────┐
  │  第 4 步：矿机连进来，开始加密转发                      │
  │  ────────────────────────────────────────────────────  │
  │  矿机 ─明文─▶ 客户端3333端口 ─加密─▶ 1.2.3.4:9999      │
  │  矿机 ◀─明文─ 客户端3333端口 ◀─加密─ 1.2.3.4:9999      │
  └────────────────────────────────────────────────────────┘
```

### 2.3 有两条线，别搞混

这是最容易理解错的地方：

```
                    ┌─────────────────────────────┐
                    │                             │
   ┌──────────┐     │  ① 控制线（一直连着）        │     ┌─────────┐
   │          │─────┼─────────────────────────────┼────▶│         │
   │  SSLMIX  │     │  拿配置、收指令              │     │ 服务器  │
   │  客户端  │     │  不传矿机数据               │     │         │
   │          │     └─────────────────────────────┘     │         │
   │          │                                         │         │
   │          │     ┌─────────────────────────────┐     │         │
   │          │─────┼═════════════════════════════┼════▶│         │
   │          │     │  ② 数据线（矿机来了才建）    │     │         │
   └──────────┘     │  加密的，走真实挖矿流量      │     └─────────┘
                    └─────────────────────────────┘
```

**加密发生在第 ② 条线上**。控制线只传几条指令，不传你的挖矿数据。

### 2.4 两个版本的区别

| | **sslmix** | **eccp256mix** |
|---|---|---|
| 加密方式 | 标准 TLS | ECC 椭圆曲线 + TLS + WebSocket 伪装 |
| 伪装程度 | 像 HTTPS | 像在访问某个网站的 WebSocket |
| 需要域名 | ❌ 不需要 | ✅ **必须有域名** |
| 隐蔽性 | 一般 | 更好 |
| 本教程针对 | ✅ | 配置方法相同，只是文件名不同 |

## 三、安装

### 3.1 先确认你的系统架构

不知道就先试 **amd64**，不行再试 arm。或者在 Linux 上执行：

```bash
uname -m
```

| 输出 | 对应架构 | 下载哪个包 |
|---|---|---|
| `x86_64` | amd64 | `ssmixlinux` |
| `armv7l` | arm32 | `ssmixlinux32armv7l` |
| `aarch64` / `armv8` | arm64 | `ssmixlinux64armv8l` |

### 3.2 方式一：一键脚本（推荐，自动配好开机启动）

```bash
bash <(curl -s -L https://raw.githubusercontent.com/FxPool/SSLMIX/main/install_zh.sh) https://raw.githubusercontent.com/FxPool/SSLMIX/main ssmixlinux
```

> arm 架构把命令末尾的 `ssmixlinux` 换成 `ssmixlinux32armv7l` 或 `ssmixlinux64armv8l`。

执行后会出现菜单：

```
     脚本版本: x.x  平台: ssmixlinux
     0. 退出
     1. 安装          ← 第一次装选这个
     2. 更新
     3. 卸载
     4. 启动
     5. 停止
     6. 重启
     7. 开启开机启动   ← 装完建议开一下
     8. 关闭开机启动
     9. 设置最大连接数(重启生效,默认已经开启)
     10. 查看最大连接数

请输入选择 [0-10]:
```

输入 `1` 回车开始安装，装完再选 `7` 打开开机启动。

### 3.3 方式二：手动安装

```bash
# 下载
wget https://github.com/FxPool/SSLMIX/raw/main/ssmixlinux.tar.gz

# 解压
tar -zxvf ssmixlinux.tar.gz

# 进目录
cd ssmixlinux

# 运行
./running
```

解压后目录里有两个文件：

```
ssmixlinux/
├── running    ← 守护进程，启动它
└── sslmix     ← 主程序，由 running 拉起
```

> **一定要运行 `./running`，不是 `./sslmix`。** running 会在主程序挂掉时自动把它拉起来。

**后台运行**（关掉 SSH 也不停）：

```bash
setsid ./running &
```

如果 `setsid` 不可用：

```bash
nohup ./running > /dev/null 2>&1 &
```

> 手动安装**不会**自动配置开机启动，服务器重启后要自己再运行一次。

## 四、配置

装好了先别急着启动，**还差一个配置文件**，没有它程序不知道要连哪。

### 4.1 找管理员要配置文件

配置文件从后台管理页下载，长这样：

```
┌──────────────────────────────────────────────────────────────┐
│  隧道加密                                        添加 API 地址│
├──────────────────────────────────────────────────────────────┤
│  加密方式   API 地址              监听状态  在线数  操作      │
├──────────────────────────────────────────────────────────────┤
│  SSLMIX     8.218.160.115:4562    监听中      0     ↓ >_ ♺ ✎ 🗑│
│                                                    ↑          │
│                                              点这个下载       │
└──────────────────────────────────────────────────────────────┘
```

下载下来是一个叫 **`apiSslMixConfig.json`** 的文件。

### 4.2 放到正确的位置

**必须和程序放在同一个文件夹里**：

```
ssmixlinux/
├── running
├── sslmix
└── apiSslMixConfig.json   ← 放这里
```

一键脚本安装的话，默认路径是 `/root/ssmixlinux/`：

```bash
# 用 scp 从你电脑传到服务器
scp apiSslMixConfig.json root@你的服务器IP:/root/ssmixlinux/
```

> ⚠️ **文件名不能改**。必须一字不差是 `apiSslMixConfig.json`。
> 如果你用的是 eccp256mix 版本，文件名则是 `apiEccp256mixConfig.json`。
>
> 浏览器下载时如果自动加了序号变成 `apiSslMixConfig (1).json`，**要改回来**。

### 4.3 方式二：网页上传

如果装的是带界面的版本，也可以通过网页传：

1. 浏览器打开 `http://你的服务器IP:62440`
2. 找到上传配置文件的入口，选择文件上传
3. **上传完必须重启程序才生效**

### 4.4 重启使配置生效

```bash
# 一键脚本装的：重新运行脚本，选 6 重启
# 手动装的：
pkill running
cd /root/ssmixlinux && setsid ./running &
```

### 4.5 确认成功

看控制台输出，出现下面这样就对了：

```
#======================================================
#   sslmix
#   System Required: CentOS 7+ / Debian 8+ / Ubuntu 16+
#   Version: 1.6.0
#======================================================
公告内容会显示在这里
Domain:
Name: 我的隧道
UUID: 1735689600000000000
#==========================================================
Total-conn:0                      ← 当前连进来的矿机数
Total-Worker-Package:0            ← 矿机发出去的包数
Total-Server-Package:0            ← 服务器回来的包数
Conn-Port-01:3333,Note:[BTC][矿场A]   ← ✅ 关键！有这行说明配置拿到了
Web-acc:http://*.*.*.*:62440      ← 网页管理地址
#==========================================================
```

**看 `Conn-Port-01` 这行**：

- ✅ **有这行** → 配置成功，可以让矿机连 `3333` 端口了
- ❌ **显示 `Error: No proxy info`** → 服务器没给转发配置，去后台检查"自定义本地地址"填了没

## 五、把矿机指过来

### 5.1 改矿机的矿池地址

进矿机后台（一般是浏览器打开矿机 IP），把矿池地址改成：

```
   原来：  stratum+tcp://原来的矿池地址:端口
                          ↓ 改成
   现在：  stratum+tcp://装SSLMIX那台机器的IP:3333
```

**举例**：SSLMIX 装在 `192.168.1.100`，控制台显示 `Conn-Port-01:3333`

```
┌──────────────────────────────────────────────┐
│  矿机后台 - 矿池设置                          │
├──────────────────────────────────────────────┤
│  Pool 1 URL : stratum+tcp://192.168.1.100:3333│
│  Worker     : 你的钱包.矿机编号   ← 不用改     │
│  Password   : x                   ← 不用改     │
└──────────────────────────────────────────────┘
```

**钱包地址、矿工名、密码全都不用改**，只改 URL 这一行。

### 5.2 验证有没有通

改完等 1～2 分钟，看 SSLMIX 控制台：

```
Total-conn:5                 ← 从 0 变成 5，说明 5 台矿机连上来了 ✅
Total-Worker-Package:1284    ← 数字在涨 ✅
Total-Server-Package:1109    ← 数字在涨 ✅
```

三个数字都在涨 = 一切正常。

同时到矿池后台看算力，正常上来就成了。

## 七、遇到问题怎么办

### ❌ 启动就报「请上传api配置文件到当前目录」

```
原因：找不到配置文件
```

**检查清单**：

1. 文件在不在程序同一个目录？
   ```bash
   ls -l /root/ssmixlinux/
   # 应该能看到 apiSslMixConfig.json
   ```
2. 文件名对不对？不能是 `apiSslMixConfig (1).json` 这种
3. 传上去有没有损坏？
   ```bash
   cat /root/ssmixlinux/apiSslMixConfig.json
   # 应该能看到 {"api_url":"...", ...} 这样的内容
   ```

### ❌ 显示 `Error: No proxy info`

```
原因：连上服务器了，但服务器没下发任何转发配置
```

不是你这边的问题，**找管理员**，让他在后台「自定义本地地址」里填上转发规则，格式是：

```
本地端口-远程地址:远程端口-[备注]
```

填完让他点「通知客户端更新」。

### ❌ 一直显示 `start connect server` 连不上

```
原因：网络不通，或服务器地址/端口不对
```

```bash
# 测试能不能连到服务器（IP 和端口问管理员要）
telnet 8.218.160.115 4562

# 或者
nc -zv 8.218.160.115 4562
```

- 连不上 → 检查本机防火墙、服务商安全组，或者服务器那边没启动
- 能连上但客户端还是报错 → 配置文件可能是旧的，重新下载一份

### ❌ 矿机连不上 3333 端口

```bash
# 在装 SSLMIX 的机器上确认端口开着
netstat -tlnp | grep 3333
```

- 没有输出 → 程序没起来或没拿到配置，回看第四章
- 有输出但矿机连不上 → 防火墙挡了：
  ```bash
  # CentOS
  firewall-cmd --add-port=3333/tcp --permanent && firewall-cmd --reload
  # Ubuntu
  ufw allow 3333/tcp
  ```

### ❌ 矿机连上了但矿池没算力

```
Total-conn 有数字，但 Total-Server-Package 一直是 0
```

说明矿机连到客户端了，但客户端连不通服务器。这是**服务器那边的转发目标配置错了**，找管理员检查「自定义本地地址」里的远程地址对不对。

### ❌ eccp256mix 启动就退出，日志有 `domain is not configured`

```
原因：这个版本必须配域名
```

找管理员在后台把「TLS 域名」填上，然后重新下载配置文件。

### ❌ 服务器重启后就不工作了

没设置开机启动。重新跑一键脚本选 `7`，或者手动加 crontab：

```bash
crontab -e
# 加入这一行
@reboot cd /root/ssmixlinux/ && setsid ./running &
```

## 八、安全提醒

1. **配置文件要当密码看待**
   `apiSslMixConfig.json` 里存着服务器地址和你的 token，加密强度很弱，拿到文件的人可以直接解出来。不要发到群里、不要传到网盘。

2. **Web 管理端口（62440）不要开放到公网**
   只在内网访问，或者用防火墙限制来源 IP。

3. **服务端可以在你的机器上执行命令**
   程序支持接收服务端下发的 shell 指令并执行（Linux 下）。装之前要确认你信任提供服务的这一方。

4. **建议用单独的机器或容器跑**
   不要和其他重要业务混在一台机器上。
